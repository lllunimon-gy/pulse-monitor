# 验证范围与证据

CI 在 macOS 上执行 Swift Package 单元/边界/实际 RunLoop 测试，运行 Python 回归工具测试，
构建 iOS Simulator 示例，再安装启动并保存截图。模拟器检查用于编译、启动和布局，
不代表真机性能、低内存或能耗验收完成。

运行检查固定在 macOS 15 / Xcode 16.4；另一任务在 macos-latest 编译包与 Release 示例，
同时覆盖可复现的运行基线和最新 SDK。自动卡顿实验在 scene 进入 active 后触发，
失败时也保留截图及示例事件档案。功能分支通过 PR 验证，避免 push/PR 重复启动模拟器。

## 自动化覆盖

- 阈值、去重、恢复 ID、空闲与生命周期。
- 采样间已经结束的区间、多区间历史、结束时间精度、发现轨迹保留、惰性现场采集。
- 有界交付、慢消费者的恢复容量、合并/丢弃统计、停止后的排队失效。
- 旧档案兼容、批量 upsert、字节上限、损坏保留、失败重试、诊断包往返。
- Span 父子关系/容量/幂等结束，CPU 多核心差分和重置。
- 可变刷新预算、后台间隔重置、帧窗口容量。
- 弱观察不持有对象，会话 unknown，MetricKit 规范化去重与容量。
- 回归工具拒绝设备/单位不匹配、Debug、不足五次、非有限值。
